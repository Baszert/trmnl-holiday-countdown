# Countdown

Count down to your (holi)day. Pick a date and a theme, add your own texts, and get a big day counter surrounded by themed emoji.

<a href="https://trmnl.com/recipes/188160"><img width="150" alt="Works with TRMNL" src="https://trmnl.com/images/brand/badges/light/works-with-trmnl/trmnl-badge-works-with-light.svg" /></a>

## Settings
- **Date:** the day you count down to
- **Theme:** Christmas, Valentine, Easter, Summer, Autumn, Birthday, Sale, Halloween, New Year, Wedding, Baby, Travel, St. Patrick's, Kingsday, Formula 1, Biking or Random mix
- **Top / bottom text:** shown above and below the number
- **On the date:** text shown when the day has arrived

### Develop locally

Templates and settings live in [`src/`](src/), ready for [trmnlp](https://github.com/usetrmnl/trmnlp):

```sh
gem install trmnl_preview
trmnlp serve
```
